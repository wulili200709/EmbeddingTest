# 本机测试项目

这里保存需要继续编辑、复测的项目输入和配置。除本说明外，目录内容默认不进入 Git。

- `localization_groups/product_1125/`：现有定位组测试产品；保留模型、ROI 绑定、组参数和训练图片。使用根目录 `run_roi_group_demo.bat` 打开。它独立于正式产品配方。
- `lens_calibration/real_image/`：从旧报告目录迁移的实拍标定测试项目，包含原参数和当时的验证证据。
- `lens_calibration/single_view/`：原单张合成测试项目。合成参数仅用于演示，不能用作实际相机标定。
- `lens_calibration/profiles/`：镜头 Demo 新参数的默认保存位置；迁移时导入的参数副本与原文件逐字节一致。

新报告、导出图片和日志存入 `artifacts/reports`。旧报告中的静态证据不等同于当前项目参数；复测时以实际加载的参数文件为准。

这些项目可能引用 `MVS/Data` 或其他目录中的实拍原图；本次整理保留外部原图路径，不移动现场图片。旧路径通过本机目录联接保持兼容，不能将联接当作独立副本进行递归清理。
