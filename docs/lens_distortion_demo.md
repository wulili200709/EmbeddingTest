# 镜头畸变矫正 Demo

## 在主程序中选择是否应用矫正

完整版从“工具 → 镜头矫正设置…”进入。默认各相机关闭、未选参数，不会自动导入以前的实验标定文件。

1. 在设置表中选中对应的物理相机，检查序列号，点击“标定与预览…”。标定窗口顶部显示产品、物理相机和序列号，固定对应打开时选中的相机。加载这台相机拍摄的完整标定板原图，完成计算并用产品原图验证；此窗口目前使用离线图片，不会自行连接相机采图。
2. 点击“应用到 camX”，当前结果会直接保存到产品并启用此相机的矫正，无需手动导出再导入。这里仅更新窗口所对应的相机，不会提交设置表中其他相机尚未保存的修改。“更多 → 导出参数 JSON…”仍只导出文件，不改变生产设置；已有文件也可以在设置表中显式导入、勾选并保存。多台相机分别配置；单相机多光源模式的通道共用该物理相机的镜头参数。模拟示例和手动试调不能通过“应用到 camX”用于生产。
3. 在开启矫正的状态下建立模板、定位组和检测 ROI，并重新训练检测工具。原图与矫正图、不同参数版本的模板、ROI 配置和模型分别保存，不直接搬用原图的 ROI 坐标。
4. 拍照后执行一次矫正，随后定位、ROI 跟随、检测与预览共用这张矫正图。日志中的 `correction` / 调试状态中的 `remap` 记录实际处理时间。映射表会预建并缓存；CT 仍会增加每帧 remap 的时间，具体以本机实测为准。
5. 关闭后恢复原图流程及原有模型。重新标定后需再次显式导入新参数并保存；系统不按文件修改时间自动寻找“最新文件”。

参数按产品保存在 `lens_correction_settings.json`，导入的不可变参数副本位于 `calibration/profiles`；矫正版本的模板和检测项位于 `lens_assets`。产品原始图片和标注不会被覆盖，矫正样本缓存位于产品的 `.cache/lens_images`。图片尺寸或已绑定的相机序列号不匹配时会报告错误，不会自动缩放参数或悄悄退回原图检测。

开启时应使用完整相机原图。HALCON 导出的局部裁剪小图缺少完整传感器坐标，不能直接套用全图标定参数；这类旧流程在关闭矫正时保留。镜头矫正也不能消除立体产品不同高度产生的全部视差，已有定位组逻辑仍按原算法运行。

## 单独启动 Demo

在 `EmbeddingTest` 文件夹双击 `run_lens_distortion_demo.bat`。使用本机 Python 3.12、OpenCV、NumPy、SciPy 和 PySide6，无需连接相机。也可运行：

```powershell
py -3.12 tools/lens_distortion_demo.py --single-example
```

启动时展示一张**待计算的模拟棋盘图**，默认开启“自动识别”，间距为 2 mm。点击“计算标定”即可运行角点检测、求参和矫正；“更多 → 模拟示例 → 棋盘格”可重新载入该示例。自动模式无需填写行列数，识别后显示可见网格范围和实际使用的角点数。

“更多 → 模拟示例 → 长针位”展示人为加入桶形畸变的长针位图，再按已知参数矫正，用于观察图像变化；命令行 `--example` 也可直接载入该图。这两种模拟示例都不能代表实际相机的精度。Demo 生成和保存自己的文件，不更改 LC System 的相机设置、模板或产品配方。

参数对话框默认使用 `experiments/lens_calibration/profiles`，矫正图片默认导出到 `artifacts/reports/lens_distortion_demo`，仍可在文件对话框中选择其他位置。已有标定 JSON 可从原位置加载，无需重新标定。`--image`、`--profile`、`--example` 和 `--single-example` 的用法不变；可额外传入 `--workdir "D:/实验工作区"` 改变上述默认目录，输入图片和参数仍按显式传入的路径读取。启动失败日志保存在该工作区的 `artifacts/reports/lens_distortion_demo/startup_error.txt`。

## 用一张 2 mm 棋盘格原图标定

1. 保持生产时的镜头、焦距、对焦、分辨率和采图裁剪方式。拍摄一张清晰、平整、不反光的棋盘格原图，棋盘应尽量覆盖检测区域，特别是长针位左右两端。打印纸或柔性胶片须固定在平整硬底板上，不能悬空起皱；纸张和打印尺度误差不能作为镜头误差补偿。请勿使用缩略图、截图或已经矫正的图像。
2. 在“标定”中选择模式。默认“单张 · 径向”用于桶形、枕形畸变；若还需要消除测量平面的近大远小，选择“单张 · 径向＋透视”，并把标定板放在实际被测部位所在的平面。
3. 保持“自动识别”勾选，棋盘行列尽量接近图像的水平 / 垂直方向。此模式允许棋盘被画面裁切，以及部分角点被编码块遮挡，不读取编码内容。若使用完整普通棋盘，也可取消自动识别，手动填写**内角点列数和行数**：例如 10 列 × 7 行格子，对应 9 列 × 6 行内角点。若 2 mm 是单个格子的边长，“点间距”填写 2.000 mm。
4. 选择一张标定图片，点击“计算标定”。计算在后台进行，显示角点、覆盖情况及拟合误差。失败时查看提示，确认点数、清晰度和棋盘覆盖范围。
5. 点击“打开原图…”，选取同分辨率的产品原图。建议另外拍摄未参与求参的标定板图片，验证边缘直线和格距，再评估产品效果。验证图片不必参与求参。
6. 点击“更多 → 导出参数 JSON…”，下次直接加载。单图参数记录校正模式、图像尺寸、固定校正中心、径向系数、平面映射、角点及误差等信息；自动模式额外保存每个实测角点的网格索引（v2 格式），不会补造缺失角点。旧版完整棋盘单图及多姿态参数仍可加载。

单图模式把**校正中心固定在图像中心**，拟合规则网格的平面映射与两个径向系数；这不是独立求解完整相机内参，也不包括切向畸变或鱼眼模型。输出误差是对当前标定角点的拟合误差，不等于独立测量精度。仅在图像中央识别到少量格子时，视野两端属于缺少标定点约束的外推区域；应补充覆盖更大的原图。

这是本 Demo 独立实现的单图模型，操作方式参考工业标定流程；不声称与康耐视或海康的内部算法相同，也不能直接加载它们的专用标定文件。

“单张 · 径向”保留原来的透视关系；“单张 · 径向＋透视”把标定平面的格点恢复为等距网格，输出方向由棋盘行列方向决定，可能旋转画面。平面映射适用于标定板所在平面，不保证不同高度表面的毫米尺寸正确。格距可以记录为 2 mm，但尺寸精度与公差仍需在实际测量平面验证。

## 可选的多姿态模式

“多姿态”保留旧的相机标定方法，支持棋盘格和对称圆点阵。此模式在 Demo 中仍要求至少 10 张完整识别、像素内容不同且分辨率一致的原图，建议采集 15～20 张不同位置与倾角的照片。这个数量是该模式的采集门槛，不是所有畸变矫正算法的统一要求。

多姿态模式计算相机内参、五个畸变系数和各张图片的姿态；单图模式使用不同的求解模型，两类参数通过各自的文件格式保存和识别。

## 对比与试调

- 两幅图支持滚轮同步缩放、左键拖动和“适应窗口”。“更多 → 参考网格”是固定的直线参考，不改变图像内容。
- 单图模式使用与原图相同大小的固定画布，“视野保留”不可调。径向模式保持原像素坐标尺度和中心；联合模式以棋盘中心附近的尺度确定等距网格。矫正后允许黑边，也可能有内容超出画布，不能将“尺寸不变”理解为“完整视野保证保留”。
- 多姿态和手动模式的“视野保留”可在 0～1 之间调整：0 减少黑边但可能丢失边缘视野；1 尽量保留视野并允许黑边。变化后会重新生成映射表。
- “手动预览”允许调整 k1、k2，用假设的内参快速观察补偿方向。其结果明确标记为试调，不能代替标定板求参。请用标准板判断，不要依照产品缺陷把真实弯针调直。
- “更多 → 测量矫正耗时”预热后计时 20 次，显示中位数和 P95。计时包括查表矫正和输出图分配，不包括建表、读图、界面显示及其他检测算法。实际生产节拍需接入后另测。
- “更多 → 导出矫正图…”保存无网格的完整分辨率结果，并附带同名 `.undistortion.json` 记录。不要覆盖相机原图；重新打开带有这份记录的矫正图时，Demo 会提示避免重复矫正。

## 文件与限制

- 单图算法：`algorithms/lens_single_calibration.py`
- 自动可见网格识别：`algorithms/lens_grid_detection.py`
- 多姿态与手动算法：`algorithms/lens_calibration.py`
- 界面：`tools/lens_distortion_demo.py`
- 启动：`run_lens_distortion_demo.bat`
- 参数只用于原始标定尺寸。加载不同分辨率的图片时会提示，不会自动缩放内参或图像。
- 标定图必须来自同一套相机/镜头设置；仅尺寸相同不能证明来自同一相机。
- 更换镜头、改变焦距、对焦或采集裁剪方式后，需要重新验证或标定。联合透视模式还要求相机与测量平面的距离、角度保持一致。
- 单图自动模式支持接近水平 / 垂直的规则棋盘，并尝试跳过编码块占据的区域；不解码专用标记，不保证支持任意厂商板型、大幅旋转、强透视或严重反光。检测到跳格、网格冲突或覆盖不足时应重新拍摄，不能只靠调整行列数强行通过。多姿态模式还支持对称圆点阵；不支持鱼眼模型、专用编码定位或非对称圆点阵。
- 固定光心的单图模型有适用范围。如果镜头存在明显偏心、切向畸变，或格点残差仍呈有规律的变化，需要采用更合适的模型，不能靠反复调整产品图把真实弯针“校直”。
- 几何矫正不能恢复失焦、运动模糊、过曝、遮挡等造成的图像信息损失。
