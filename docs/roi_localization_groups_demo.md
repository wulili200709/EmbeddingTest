# 自定义定位组测试版

定位组也已接入正式程序源码，正式入口与配置说明见 [正式程序说明](roi_localization_groups.md)。以下独立测试入口继续保留。

双击项目目录中的 `run_roi_group_demo.bat`，打开“自定义定位组测试版 · 独立副本 · LC System”。需要本机已安装的 Python 3.12 及项目依赖。

启动入口：`tools/roi_group_demo.py`。默认测试副本目录为 `experiments/localization_groups/product_1125`。已有副本会直接打开，保留用户修改，不再依赖某个版本的 `dist` 目录。首次没有副本时，界面会让你选择源产品目录（目录内应有 `shape/cam1/recipe.json`），然后复制模板、配方和训练图片；取消选择不会创建副本。也可显式指定：

```powershell
py -3.12 tools/roi_group_demo.py --source-product "D:/产品目录/1125"
```

`--prepare-only` 只准备副本，不打开界面；首次使用此选项必须同时指定 `--source-product`。`--product-dir` 可指定另一个测试副本，`--workdir` 可指定实验与报告的根目录。已有新目录优先使用；新目录不存在而旧 `reports/localization_groups_demo/product_1125` 仍存在时，直接复用旧副本，不重新复制覆盖。源产品与原发布程序保持原样。

## 操作

1. 在 **定位组** 页点击 **新建定位组**，填写名称，例如“上排左端壳体”。
2. 在右侧参考图上用**鼠标左键拖动**画矩形定位区域。选择清晰、稳定、有区别的壳体边角；不要用待检的弯针、缺字或缺件本身定位。滚轮缩放，中键拖动平移。
3. 在 **参考 ROI（Reference ROI）** 页选中已有检测 ROI，通过 **所属定位组** 下拉框选择该组。一个组可以带多个检测 ROI；未分组 ROI 保持全局跟随。
4. 点击 **保存定位组及 ROI 配置**（或 Reference ROI 页的保存按钮）。
5. 在 **匹配测试（Find）** 页选择照片，点击 **运行所选（Run Selected）** 或 **运行全部（Run All）**。首次默认加载原始 BMP，保证与此产品的原始参考图一致。界面跟随程序的中英文设置。
6. 切换 **启用定位组** 开关后重新运行同一张图，对比只使用全局定位和使用组修正的效果。关闭开关只影响这次测试，不会删除已保存的绑定。

灰色细框是全局预计位置，彩色框是最终检测 ROI。下方表格显示每组相关分数、横纵修正量及状态。红色 INVALID 框仅用于诊断，表示此组无效；任何已绑定组失败，整次定位都标为失败，不能作为检测合格结果。

此功能修正的是检测 ROI 的位置，不会重新变形或导出一张矫正后的产品图。

## 参数与边界

- **搜索半径**：在全局预计位置周围允许的局部位移，单位为参考图像素，默认 64。先根据实际偏差设定；重复端子应尽量限制范围，避免找到邻格。
- **最低相关分数**：默认 0.65，局部灰度归一化相关分数（0–1）。与全局模板分数（0–100）是不同指标。
- **最小候选分差**：默认 0.03，检查是否存在分数相近的其他位置。有歧义时，应选更有区别的定位结构或限制搜索范围。
- 第一版只修正组内平移，全局旋转/尺度仍来自原有模板匹配。不会把一组任意拉伸成另一种形状；跨度大、不同高度或不同运动的区域应拆组。
- 低纹理、超出图像、搜索边界命中、分数不足、候选歧义、失效绑定均明确失败。失败后不会沿用上一帧结果。
- 换参考图后已有定位组标为需重画。未绑定的草稿组不参与检测；已绑定但未画定位框的组会失败。删除已绑定组时会列出相关 ROI，点击“删除组，ROI 改为全局定位”才会删除组并解除绑定；检测 ROI 本身保留。取消则保持原配置，也可先在 Reference ROI 改绑其他组。
- 参考图与测试图应使用相同相机分辨率和相同畸变矫正状态。需要测试矫正图时，先用对应矫正参考图重建全局模板，再重新确认定位组。

## 验证方法

用同一产品在左、中、右和上下位置的照片，保持检测 ROI 与定位组设置不变，分别运行开关两种状态。重点记录每个检测 ROI 对实际结构的最大位置偏差，不以匹配分数或修正量代替精度。

定位区域应避开被测缺陷，并加入实际 NG 样本验证，防止定位框跟随异常而掩盖问题。定位组仅提供局部跟随，不能消除所有立体视差或恢复被遮挡特征。

新目录中的测试配置存于 `experiments/localization_groups/product_1125/shape/cam1/recipe.json`；使用旧目录兼容路径或 `--product-dir` 时，保存在实际打开的副本内。启动失败日志存于 `artifacts/reports/localization_groups_demo/startup_error.txt`。配方包含 v2 分组字段，测试时请使用此源码测试入口，不要将该配方直接交给尚不支持分组的旧发布程序。
