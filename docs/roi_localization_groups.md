# 正式程序：自定义定位组

定位组已接入正式程序源码，与模板测试、图片检测和在线帧检测共用同一套定位逻辑。本次不生成安装包或 EXE；运行源码入口 `Main.py` 才会使用这些源码更新，已发布的旧 EXE 不会自动更新。

## 入口与使用

1. 在正式程序选择产品和相机，进入 **工具 → 工程调试工具 → Shape位置修正工具**。
2. 在 **定位组** 页新建并命名分组，在右侧参考图画该组的矩形定位区域。可以自由命名为上排、下排、左上壳体等，不限定方向。
3. 在 **参考 ROI** 页选中检测 ROI，通过 **所属定位组** 下拉框绑定。一个组可以带动多个 ROI；选择 **全局定位** 的 ROI 仍使用全局模板定位。
4. 点击 **保存定位组及 ROI 配置**。配置与该产品、该相机的形状配方一起保存，并通知正式检测端重新加载。
5. 在 **匹配测试** 页添加同一产品不同位置的照片，运行所选图片或全部图片。打开、关闭 **启用定位组** 后重新运行，可对比组修正与全局定位的结果。这个开关只影响测试，不会解除保存的绑定。
6. 使用正式图片检测或在线检测时，选择 Shape 位置修正流程；程序按配方执行已保存的 ROI 绑定。

界面跟随主程序中英文设置，已打开的定位组页、ROI 绑定选项、结果表和已缓存的分组失败说明也随之刷新。用户自行填写的组名和 ROI 名保持原样。

模板窗口保存到打开它时对应的产品、相机。切换产品时会先处理尚未保存的模板修改；选择取消则保持当前产品。只打开窗口查看不会自动改写旧配方。

## 结果与范围

先由全局模板确定整体姿态，再让每个已绑定的定位组在预计位置附近独立寻找稳定特征，计算局部平移，带动它绑定的 ROI。当前每组使用一个矩形定位区域，局部修正只包含平移；全局旋转和尺度仍由原模板提供。

匹配测试中，灰色框表示全局预计位置，彩色框表示组修正后的 ROI。表格显示相关分数、横纵修正量和失败原因。任何已绑定定位组失败，整次定位返回失败，失败框仅用于诊断，检测端不会沿用旧位置继续推理。

换参考图后需要重画已绑定组的定位框。删除已绑定组时，可以明确选择删除组并让相关 ROI 改用全局定位；ROI 本身保留。取消删除则保持原配置。

定位组修正 ROI 的位置，不生成畸变矫正图。请用稳定且有区别的结构定位，并以 ROI 相对真实检测位置的偏差验证效果；相关分数高不等于测量精度高。

## 配置兼容

- 没有定位组的旧配方继续按原来的全局定位运行。
- 分组及 ROI 绑定保存在产品目录的 `shape/<相机>/recipe.json` 中。配置使用 v2 字段，不应交给不支持定位组的旧程序运行。
- 独立测试版默认在 `experiments/localization_groups/product_1125` 保存配方；也兼容尚未迁移的旧 `reports/localization_groups_demo/product_1125`。测试副本不会自动覆盖正式产品。正式程序里需要为所选产品设置并保存定位组。
- 独立测试版的操作和参数说明见 [测试版说明](roi_localization_groups_demo.md)。

## 开发验证

在项目目录使用 `py -3.12 -m unittest discover -s tests -p 'test_localization*.py' -v` 运行定位组验证。测试使用临时产品和离屏界面，覆盖配置兼容、局部定位、失败拦截、界面保存与重开，以及正式工具入口到检测上下文的配置刷新。
