# 50-2 长直边取样候选结果

本目录是对用户所画 B2 长红线的离线试验，输入为 `50-2` 目录中 2026-09-17 的原始 50 张图。测点仍为四个横槽中的 12 个小开口。仅改动结构相似的 `T2`、`B2`：中心取样宽度由 49 列扩到 **181 列**，上边缘暗侧比例由 3% 调到 **20%**，下边缘仍为 3%。其余 10 处保持旧配置。配置见 [`config/examples/50-2_opening_gaps_long_edge_candidate.json`](../../config/examples/50-2_opening_gaps_long_edge_candidate.json)。

| 测点 | 原 49 列、上侧 3%：50 张中位值 / 极差 | 候选 181 列、上侧 20%：50 张中位值 / 极差 |
| --- | ---: | ---: |
| T2 | 83.522 / 4.496 px | **115.521 / 0.634 px** |
| B2 | 82.478 / 2.735 px | **114.007 / 0.716 px** |

宽度单独加到 81 列但保持上侧 3% 时，B2 极差仍为 1.703 px，而且上边缘仍落在用户红线下方。修正上边缘定义后，紫色短线回到亮暗交界附近。进一步扩大到 181 列时，50 张重复读数的极差继续下降。对其他位置盲目加宽并不总能改善，例如 T1 的极差从 49 列的 0.540 px 增至 81 列的 0.717 px，因此没有统一改宽。

逐图读数见 [`50-2_dark_plateau.csv`](50-2_dark_plateau.csv)，最小、最大值及极差见 [`summary.json`](summary.json)。在 [`edge_viewer.html`](edge_viewer.html) 中可选择 B2，查看 181 列实际找到的上下边缘轮廓、最终中位数对应的短线和原图。

**限制：**这是在同一批 50 张图上试出来的候选参数，只对 B2 的人工红线截图进行了位置对照；T2 和其他 10 处缺少逐处人工边缘标注。600/600 处获得读数、12 处极差均低于 1.5 px，并不等于实体边缘都正确或 Cgk 已通过。新产品的 EXE 配方尚未更改。
